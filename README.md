# CyImGUI

👋Hello! Cy Client is Cyboxias Minecraft Java client. His plan was to have it include ONLY modules that are for practical use, as clients like Lunar Client have a bit too many features, all of which chip away at performance.

> CyImGUI WAS just a simple Fabric mod. maxyphor Forked it, and turned it into ImGUI, for better visuals and stuff.
>
> um

<br />

⌨️ The in-game ClickGUI is accessible through Right Shift, but it can be rebinded in the settings tab. Each module can be toggled respectively with the keybind you set it on.
